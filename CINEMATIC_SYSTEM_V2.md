# 🎬 Кинематографичная система v2 — как поднять качество и связность роликов

> Документ-апгрейд к текущей продакшн-библии (пример: «INNER MONOLOGUE / Anendophasia»).
> Цель: **единый кинематографичный стиль**, **сцены, которые перетекают друг в друга**, и **инфографика без огромных текстов на экране**.

---

## 0. Диагноз: что сейчас ограничивает качество

Текущий пайплайн: `18 отдельных кадров (NBP) → каждый анимируется отдельно (Veo) → CapCut (крупный текст + звук)`.

Три структурные проблемы:

| Проблема | Почему возникает | Что чувствует зритель |
|---|---|---|
| **Дрейф стиля** между сценами | Каждый из 18 кадров NBP генерится «с нуля» по текстовому описанию. Даже при повторении `GLOBAL STYLE LOCK` модель каждый раз заново выбирает зерно, контраст, оттенок света. | Палитра/грейн/свет «плавают» от сцены к сцене — ощущение сборки из разных источников. |
| **Нет связности** (слайд-шоу) | 18 независимых клипов склеены 2-кадровым кросс-фейдом. Движение внутри сцены не продолжается в следующую. | Похоже на листание карточек, а не на единый фильм. |
| **Доминирует крупный текст** | Заголовки Druk Wide 72–110pt перекрывают кадр. | Выглядит как «текстовый TikTok», а не как премиальная научная документалистика. |

Ниже — 5 апгрейдов, которые это закрывают, используя возможности **Nano Banana Pro** и **Veo 3.1** (актуально на 2026).

---

## 1. 🔒 Залочить стиль ОДИН раз — «Style DNA Kit» (foundation references)

Главная идея: перестать описывать стиль текстом в каждой сцене. Вместо этого создать **набор эталонных изображений** и подавать их как референсы в каждую генерацию.

> **Почему это работает:** Nano Banana Pro доверяет изображениям больше, чем словам, и держит до **14 референс-изображений** с консистентностью **90%+**. Это заменяет повторение `GLOBAL STYLE LOCK` в каждом промпте.

### Что генерим один раз (Style DNA Kit, 4–6 плашек):

1. **Palette / grade plate** — кадр-эталон цвета и контраста (cold neural blue + cream midtone + void black + grain). Это «якорь грейда».
2. **Lighting / grain plate** — кадр с эталонным киари-скуро светом сверху-слева и зерном.
3. **Character sheet** — повторяющийся силуэт головы в профиль (3–4 ракурса на одном листе).
4. **Motif sheet** — повторяющиеся мотивы: ухо, мозг в разрезе, sound-wave лента, blood-red ember.
5. *(опц.)* **Texture plate** — пергамент/хром/экран fMRI.

### Как использовать в каждой сцене (NBP):

```
Reference images: [palette_plate, lighting_plate, character_sheet]
Prompt: "Match the exact palette, grain, depth-of-field and lighting of the
reference images. Compose: <только описание содержания сцены, 1–2 предложения>.
Keep the recurring head-silhouette identical to the character sheet.
No text, no glyphs, no numbers anywhere."
```

Эффект: промпт сцены становится в 5 раз короче, а **look идентичен** во всех 18 кадрах. Дрейф стиля исчезает.

> Дополнительно: фиксируйте `seed` где возможно и всё равно прогоните **один общий LUT** на финальном тайм-лайне (страховка).

## 2. 🔗 Сцены, которые ПЕРЕТЕКАЮТ друг в друга — Veo 3.1 «first frame → last frame»

Это **самый большой апгрейд связности**. Veo 3.1 умеет генерировать переход между **первым и последним кадром** (`frames to video`), плюс `extend` и `ingredients` (до 3 референсов).

### Принцип «цепочки кадров»:

```
Сцена N:   first_frame = still_N      last_frame = still_(N+1)
Сцена N+1: first_frame = still_(N+1)  last_frame = still_(N+2)
...
```

Veo сам интерполирует непрерывное движение камеры/морфинг между кадрами. Теперь **сцена буквально превращается в следующую**, а не сменяется фейдом.

### Примеры match-cut переходов для этого ролика:

| Переход | Как перетекает |
|---|---|
| S1 → S2 | Камера **отъезжает от уха** — ухо становится частью силуэта головы. |
| S3 → S4 | Ряд из 10 силуэтов **сжимается** в один силуэт со светящимся словом-пузырём. |
| S6 → S7 | Вспышка бипера **переходит** в активацию зоны Брока на fMRI. |
| S8 → S9 | Чёрный «void» внутри головы **разрастается** на весь экран (вход в тишину). |
| S16 → S17 | Текст-вопрос **схлопывается** в одну красную звуковую волну (meta-twist). |

### Сквозные «якорные мотивы» (visual thread)

Запустите 3–4 объекта, которые **физически путешествуют через весь фильм** — они держат повествование:
- **Sound-wave лента** (рождается из уха в S1, исчезает в тишине S9, возвращается красной в S17).
- **Единый dust mote / частица** дрейфует через несколько сцен.
- **Blood-red ember** — бренд-акцент, появляется 2–3 раза (как и задумано).
- **Void-black «пустая голова»** — отрицательное пространство как сквозной герой.

## 3. 🎥 Единая грамматика камеры и монтажа

Чтобы 18 сцен читались как один фильм, заложите **правила, одинаковые для всех сцен**:

- **Одна линза/движение:** только медленные push-in и боковые дрейфы (без зумов-рывков). f/1.4, шэллоу DOF везде.
- **Единое направление движения:** всё дрейфует слева-направо = «мысль, которая движется». Разворот направления только на meta-twist (S17).
- **Match-cut по форме:** круг → круг (ухо → воксель → бор МРТ → рот). Глаз не замечает склейку.
- **Хард-каты только на смысловых ударах** (S8→S9 тишина, S16→S17 twist) — остальное перетекает (см. §2).
- **Темп ровный 5 сек**, но «дыхание» монтажа задаётся звуком, а не нарезкой.

## 4. 🔤 Инфографика БЕЗ огромных текстов — «данные как изображение»

Запрос: инфографика, но без гигантских надписей. Принцип: **картинка несёт данные, голос несёт смысл, текст — только микро-подпись.**

### Убрать → Заменить

| Сейчас | Замена |
|---|---|
| Заголовок Druk Wide 72–110pt на пол-экрана | **In-frame визуализация данных**: число «30–50%» = ряд силуэтов, который заполняется/гаснет (уже есть в S3 — усилить и сделать главным носителем). |
| Большой текст-слоган поверх кадра | **Микро-тайпографика**: только тонкий моно-тикер снизу (цитата источника) + 1–2 слова-кикер, ≤24–28pt, opacity 60–75%. Стиль Saul Bass — сдержанность довести до предела. |
| Текст-биллборд «50%» | **Диегетический текст**: цифры/метки живут внутри сцены (на консоли fMRI, на лабораторном деле), а не висят баннером. |

### Правило «один глиф на сцену»
На экране одновременно — **максимум один носитель информации**: либо данные-визуал, либо короткий кикер, либо цитата. Не три сразу. Остальное говорит голос.

### Кинетическая микро-типографика
Маленькие подписи, которые **появляются по буквам/словам** в ритме голоса (а не «выезжают плашкой»). Моно-шрифт (JetBrains Mono) для цитат, лёгкий Inter для кикеров. Это даёт «документальный/лабораторный» тон вместо «мемного TikTok».

> Итог: ролик выглядит как премиальная наука (Kurzgesagt × Lynch), а не как видео с крупными субтитрами.

## 5. ✨ Апгрейд качества картинки

- **Нативный 9:16 в Veo 3.1** — генерируйте сразу вертикально (Veo 3.1 поддерживает native vertical), без кропа из 16:9 → нет артефактов кадрирования.
- **Upscale до 4K → даунскейл в 1080×1920** — более чистое зерно и лучше держит сжатие TikTok.
- **Реальная глубина:** генерируйте с разделением план-фон, добавляйте лёгкий параллакс в посте (2.5D).
- **Грейн/халяция — один пасс на весь тайм-лайн**, а не по клипам (иначе зерно «прыгает» между сценами).
- **Финальный мастеринг как есть** (−14 LUFS / −1 dBTP) — звук уже сильный, не трогаем.

## 6. 🛠️ Автоматизация (предложение) — репозиторий `vestka2` как пайплайн

Чтобы единый стиль был **автоматическим и повторяемым по всей серии**, можно собрать небольшой пайплайн в этом репо:

```
scenes.yaml  (таблица сцен: line, still-prompt, motion-prompt, overlay)
   │
   ├─ 1. gen_stills.py   → Gemini Image API (NBP) + Style DNA Kit refs  → /stills
   ├─ 2. chain_video.py  → Veo 3.1 first/last-frame цепочка             → /clips
   ├─ 3. assemble.py     → ffmpeg: склейка + общий LUT + грейн + виньетка → master.mp4
   └─ 4. (CapCut только финальный полиш: микро-типографика + звук-микс)
```

Это даёт: один источник правды (`scenes.yaml`), идентичный стиль во всех кадрах, чейнинг сцен «из коробки», и быстрый ре-рендер всей серии при смене грейда.

> Для реализации нужен **Gemini API key** (доступ к NBP/Veo 3.1). Могу собрать и протестировать пайплайн, если дадите ключ.

## 7. Быстрый чек-лист внедрения (порядок)

1. Сгенерировать **Style DNA Kit** (4–6 плашек) — один раз на серию.
2. Перегенерировать 18 кадров через **reference-image lock** (§1) — убрать дрейф.
3. Перейти на **Veo 3.1 first/last-frame chaining** (§2) — сцены перетекают.
4. Запустить **3–4 сквозных мотива** (§2) — визуальная нить.
5. Срезать крупный текст → **данные-визуал + микро-тикеры** (§4).
6. Финал: нативный 9:16, 4K-upscale, один грейн-пасс (§5).
